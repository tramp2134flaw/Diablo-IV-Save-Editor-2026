## Preguntas Frecuentes

### ¿Es compatible con Windows 11?
Sí, el Diablo IV Save Editor 2026 está diseñado para funcionar sin problemas en Windows 10 y Windows 11. Asegúrate de tener los últimos drivers de hardware y software instalados para un rendimiento óptimo.

### ¿Puedo usarlo en línea o en partidas multijugador?
No, esta herramienta está pensada para modificar archivos de guardado locales. El uso en línea o en partidas multijugador puede violar los términos de servicio de Blizzard y resultar en restricciones de cuenta. Úsala bajo tu responsabilidad.

### ¿Es seguro para mi cuenta de Blizzard?
El editor modifica archivos de guardado en tu máquina local, lo que generalmente es seguro para uso offline. Sin embargo, cualquier modificación de archivos del juego puede ser detectada si se sincronizan con servidores en línea. Se recomienda usar una copia de seguridad de tus guardados y evitar modificar archivos mientras estás conectado a Internet.

### ¿Qué debo hacer si el editor no reconoce mi archivo de guardado?
Verifica que estás cargando el archivo correcto, generalmente con extensión .ods o .sav, ubicado en la carpeta de documentos de Blizzard/Diablo IV. Si el problema persiste, consulta la sección de soporte o actualiza a la última versión del editor.

### ¿Hay actualizaciones futuras programadas?
Sí, el equipo de desarrollo está comprometido a mantener el editor actualizado con cada parche y expansión de Diablo IV. Las actualizaciones se publicarán en la página de GitHub y se pueden instalar fácilmente desde el editor.
